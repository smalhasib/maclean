# Maclean

Website and downloads for [Maclean](https://smalhasib.github.io/maclean/), a disk analyzer and cleaner for macOS.

- **Download:** [Releases](https://github.com/smalhasib/maclean/releases/latest) (`.dmg`).
- **Homebrew:** `brew tap smalhasib/maclean && brew install --cask maclean`
- **Report an issue:** [Issues](https://github.com/smalhasib/maclean/issues)

This repository holds the site (`index.html`, `app.js`, `style.css`) and the published release files. The app's source is private.
